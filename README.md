# ⚡ Vast.ai GPU Price & Utilization Monitor & Dataset Collector

Веб-застосунок на **Python** з використанням **Streamlit** та **Plotly** для моніторингу цін, процентилів (P10, Медіана, P90) та утилізації GPU на платформі [Vast.ai](https://vast.ai/), а також автоматичний фоновий збирач датасету кожні 5 хвилин у **SQLite**.

---

## 🚀 Основний функціонал

### 🎛 Бокова панель (Sidebar):
- **Мультиселект GPU**: вибір популярних карт із попередньо заповненого списку (включаючи роздільні **Tesla V100 16GB** та **Tesla V100 32GB**, Tesla T4, RTX 3090, RTX 4090, A100, RTX 3070 Ti, RTX 2070, RTX A6000, RTX 3080, RTX 3070, Tesla P100, AMD MI50, H100, H200, L40S, RTX 5090 тощо).
- **Конфігурації серверів**: фільтрація за кількістю відеокарт у сервері (`1x`, `2x`, `4x`, `8x GPU`).
- **Режим цін**: розрахунок ціни за 1 GPU (`$/год за GPU`) або за весь сервер (`$/год за інстанс`).
- **Вибір періоду**: швидкі пресети (`1 день`, `7 днів`, `30 днів`, `90 днів`) та кастомний датапікер (`DateRange`).
- **Кнопка «🔄 Оновити дані»**: миттєве скидання кешу та завантаження актуальних офферів.
- **Статус SQLite бази**: лічильник збережених офферів, кількість зрізів, розмір файлу БД та кнопка примусового збереження зрізу.
- **Автоматичне оновлення**: чекбокс для оновлення сторінки кожні 30 секунд.

### 📊 Основна область:
1. **Інформаційні картки (KPI Metrics)**:
   - Кількість серверів на ринку та кількість доступних зараз.
   - Загальний відсоток утилізації ринку.
   - Мінімальна та медіанна ринкова ціна.
2. **📈 Графік динаміки цін (Plotly)**:
   - Реальні лінії **Медіана (P50)**, **P10** (нижня межа) та **P90** (верхня межа), що накопичуються в SQLite.
   - Інтерактивний боксплот розподілу цін для кожного типу GPU.
3. **⚡ Графік утилізації та доступності**:
   - **Загальний розріз за моделями**: рівень зайнятості (%) для кожної карти, історична динаміка у часі, DLPerf та надійність.
   - **🧩 Розріз за конфігураціями (1x / 2x / 4x / 8x GPU)**: групований графік утилізації для багатокарточних ригів та зведена таблиця попиту на різні конфігурації.
4. **💰 Реалістичний калькулятор дохідності хоста (Host ROI)**:
   - **Два режими розрахунку**:
     - `👤 Поодинокі карти (на 1 GPU)`
     - `🖥 Готові сервери / риги (1x, 2x, 4x, 8x GPU)` з врахуванням вартості платформи (MB, CPU, RAM, PSUs, корпус).
   - **Мультивалютний ввід**: підтримка цін у **USD ($)**, **UAH (₴)** та **CNY (¥)** з налаштовуваним курсом валют.
   - **Джерело даних**: вибір між *історичними середніми за обраний період* та *поточним Live-зрізом*.
   - **Повний розрахунок енергоспоживання**:
     - Навантаження ($W_{\text{load}}$) + Простій ($W_{\text{idle}}$) + споживання платформи.
     - ККД блоку живлення (PSU Efficiency, за замовчуванням 90%).
     - Тариф на електроенергію (за замовчуванням **$0.08 / кВт·год**).
   - **Фінансові метрики**: Валовий дохід, Витрати на світло, Чистий прибуток (день/місяць/рік), Термін окупності (місяці/дні), Річний ROI (%), Маржинальність (%), Точка беззбитковості світла ($/кВт·год), Мінімальна утилізація (%).
   - Графіки фінансового балансу, окупності та порівняння прибутковості 1x vs 2x vs 4x vs 8x ригів.
5. **📋 Зведена таблиця (Live / Історична)**:
   - Перемикання між поточним Live-зрізом та зведеною статистикою за обраний період.
   - `Модель GPU` | `Мін. ціна` | `Сер. ціна` | `Медіана` | `P10` | `P90` | `Макс. ціна` | `Утилізація (%)` | `Доступно (шт)` | `Всього серверів (шт)` | `К-сть вимірів`.
   - Кнопка **«📥 Експорт зведеної статистики у CSV»**.
6. **🔍 Детальні пропозиції (Live Offers Explorer)**:
   - Повний зріз ринку з деталями кожної машини.
   - Кнопка **«📥 Експорт поточного зрізу у CSV»**.
7. **💾 Історичний датасет (SQLite)**:
   - Перегляд усіх збережених знімків ринку кожні 5 хвилин.
   - Кнопка **«📥 Експорт повного історичного датасету з SQLite у CSV»**.

## 🤖 Фоновий збирач даних (`collector.py`)

Скрипт автоматично опитує API Vast.ai кожні 5 хвилин (300 секунд), аналізує ціни та записує повний датасет у локальну БД `gpu_history.db`.

### Запуск збирача у фоновому режимі:
```bash
nohup python3 collector.py --interval 300 > collector.log 2>&1 &
```

### Параметри `collector.py`:
- `--interval 300` — інтервал опитування в секундах (за замовчуванням 300 = 5 хв).
- `--once` — зробити один зріз ринку і завершити роботу (зручно для Cron).
- `--db gpu_history.db` — шлях до файлу SQLite.
- `--api-key <KEY>` — ключ Vast.ai API.

## ☁️ Безкоштовний деплой на Streamlit Community Cloud (з обмеженням доступу за паролем)

Застосунок повністю готовий для безкоштовного хостингу на платформі **Streamlit Community Cloud** із захистом входу паролем через `st.secrets`.

### 1. Підготовка репозиторію на GitHub:
```bash
# 1. Ініціалізувати Git (якщо ще не зроблено)
git init
git add .
git commit -m "Deploy Vast.ai GPU Price & Utilization Monitor"

# 2. Створити репозиторій на GitHub (можна Private або Public)
# 3. Підключити віддалений репозиторій та відправити код
git branch -M main
git remote add origin https://github.com/<ВАШ_GITHUB_USERNAME>/gpu_price.git
git push -u origin main
```

### 2. Створення застосунку на Streamlit Cloud:
1. Перейдіть на [share.streamlit.io](https://share.streamlit.io/) та увійдіть через GitHub.
2. Натисніть **«New app»**.
3. Заповніть поля:
   - **Repository:** `<ВАШ_GITHUB_USERNAME>/gpu_price`
   - **Branch:** `main`
   - **Main file path:** `app.py`
4. Розгорніть **«Advanced settings»** -> вкладка **«Secrets»** і вставте ваші налаштування доступу:
```toml
APP_PASSWORD = "ваш_надійний_пароль_для_входу"
VAST_API_KEY = "ваш_api_ключ_від_vast_ai"

```
5. Натисніть **«Deploy!»**.

---

### 🔒 Як працює захист доступу:
- При переході за посиланням на застосунок відвідувач бачить екран авторизації з вимогою ввести пароль.
- Доки не введено правильний пароль (`APP_PASSWORD`), жодні дані API, таблиці чи графіки не відображаються.
- Після входу сесія зберігається, а в боковій панелі з'являється кнопка **«🚪 Вийти з системи»**.

